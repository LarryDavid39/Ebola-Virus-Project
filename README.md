# Ebola-Virus-Project
Analyzed a dataset of the Ebola virus disease that occur from 2014 - 2016

### Project Overview

This data analysis project aims to provide insights into the Ebola virus disease from 2014 - 2016

### Tools

- PowerBI - Data loading, Data cleaning, Data Analysis and Building Dashboard

 ### Data Cleaning/Preparation

In the initial data preparation phase, we performed the following task:
- Data loading and inspection
- Handling missing values
- Data cleaning and formatting.

 ### Exploratory Data Analysis

EDA involved exploring the health care dataset to answer key questions, such as:

- How many countries were affected?
- What is the total number of confirmed cases?
- What is the total number of fatalities?
- What is the total number of fatality by countries?
- Which country is mostly affected(by confirmed cases and fatalities)

  ### Result/Findings

The analysis results are summarized as follows:

10 countries were affected in Africa, Europe and the USA, 6,325,462 cases where confirmed with 2,555,420 recorded fatalities.
Liberia suffered the most fatalities with 1,099,833 death. Countries like Italy, Spain, Senegal and the United Kingdom although confirmrd some cases but recorded 0 fatality.
